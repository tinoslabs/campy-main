Authenticate with the Api-Key scheme. Keys are workspace-scoped, and each one carries only the permissions you grant it.

curl {{ request.scheme }}://{{ request.get_host }}/api/v1/events/ \ -H "Authorization: Api-Key cai_xxxxxxxx.your-secret-here"

Webhooks are configured as notification channels under Alert rules. Set a shared secret there and every delivery carries an X-Campy-Signature HMAC header you can verify.
